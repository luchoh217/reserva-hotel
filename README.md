# Hotel Gran Colombia

Pequeño programa en Java que muestra la comprobación de una reserva de hotel.

## Estructura del repositorio

- `Reserva_Hotel1.java` - Programa principal
- `README.md` - Documentación del proyecto
- `.gitignore` - Archivos ignorados por Git

## Cómo ejecutar

```bash
javac Reserva_Hotel1.java
java Reserva_Hotel1
```

```text

=================================
HUÉSPED: Laura Martínez

TIPO: Suite

=================================
     ¡GRACIAS POR SU RESERVA!    
=================================
```
